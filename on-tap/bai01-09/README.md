# Ôn tập Bài 1–9

## Cấu trúc file của một đề

```
<thư mục đề>/
├── index.html                       ← trang làm bài
├── Nghe/
│   ├── Part1/
│   │   ├── audio/
│   │   │   ├── listening_1-10.mp3       ← audio câu 1–10
│   │   │   └── dap_an_nghe_1-10.txt     ← (tham khảo) đáp án 1–10
│   │   └── image/
│   │       ├── 1-5/   A.webp B.webp C.webp D.webp E.webp F.webp   ← 6 tranh câu 1–5 (D = ví dụ)
│   │       └── 6-10/  A.webp B.webp C.webp D.webp E.webp          ← 5 tranh câu 6–10
│   └── Part2/
│       └── audio/
│           ├── listening_11-20.mp3      ← audio câu 11–20
│           ├── listening_21-30.mp3      ← audio câu 21–30
│           └── dap_an_nghe_11-30.txt    ← (tham khảo) đáp án 11–30
└── Viet/
    ├── vd.webp                          ← ảnh ví dụ phần Viết
    └── 66.webp 67.webp 68.webp 69.webp 70.webp   ← ảnh câu 66–70
```

Lưu ý:
- Tên file phân biệt **chữ hoa / chữ thường**: audio dùng đuôi `.mp3` viết thường, ảnh `.webp` viết thường; tên tranh Nghe là chữ HOA `A`–`F`.
- Đáp án thật được nhúng trong `index.html`; 2 file `.txt` chỉ để tra cứu.
